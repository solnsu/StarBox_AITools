# 致谢 / Acknowledgements

更新日期 / Last updated: 2026-08-21

## 中文

StarBox 的开发离不开以下优秀的开源项目和技术：

- [OpenAI Codex CLI](https://github.com/openai/codex) — StarBox 集成了其提供的 Codex 客户端、ChatGPT 认证及相关账户能力。Codex CLI 不包含在 StarBox 安装包中，需要由用户单独安装。
- [React](https://react.dev/) — 用于构建应用的用户界面。
- [Electron](https://www.electronjs.org/) — 提供跨平台桌面应用运行环境。
- [Express](https://expressjs.com/) — 提供本地 HTTP 服务。
- [better-sqlite3](https://github.com/WiseLibs/better-sqlite3) 和 [SQLite](https://www.sqlite.org/) — 提供本地数据存储能力。
- [Zod](https://zod.dev/) — 用于运行时输入 Schema 校验。
- [Lucide](https://lucide.dev/) — 提供界面图标。
- [GSAP](https://gsap.com/) — 提供部分界面动画效果。
- [OGL](https://github.com/oframe/ogl) — 提供轻量级 WebGL 渲染能力。
- [Geist](https://vercel.com/font) 和 [Fontsource](https://fontsource.org/) — 提供并打包应用使用的 Geist 字体。
- [Vite](https://vite.dev/)、[TypeScript](https://www.typescriptlang.org/)、[esbuild](https://esbuild.github.io/)、[electron-builder](https://www.electron.build/) 和 [Vitest](https://vitest.dev/) — 提供开发、构建、打包和测试工具。

感谢这些项目的作者和贡献者对开源社区所作出的贡献。

## English

StarBox is built with the help of the following outstanding open-source projects and technologies:

- [OpenAI Codex CLI](https://github.com/openai/codex) — StarBox integrates Codex client, ChatGPT authentication, and related account capabilities provided by Codex CLI. Codex CLI is not included in the StarBox installer and must be installed separately by the user.
- [React](https://react.dev/) — used to build the application user interface.
- [Electron](https://www.electronjs.org/) — provides the cross-platform desktop application runtime.
- [Express](https://expressjs.com/) — powers the local HTTP service.
- [better-sqlite3](https://github.com/WiseLibs/better-sqlite3) and [SQLite](https://www.sqlite.org/) — provide local data storage.
- [Zod](https://zod.dev/) — provides runtime input schema validation.
- [Lucide](https://lucide.dev/) — provides user interface icons.
- [GSAP](https://gsap.com/) — powers selected user interface animations.
- [OGL](https://github.com/oframe/ogl) — provides lightweight WebGL rendering.
- [Geist](https://vercel.com/font) and [Fontsource](https://fontsource.org/) — provide and package the Geist typeface used by the application.
- [Vite](https://vite.dev/), [TypeScript](https://www.typescriptlang.org/), [esbuild](https://esbuild.github.io/), [electron-builder](https://www.electron.build/), and [Vitest](https://vitest.dev/) — provide the development, build, packaging, and testing toolchain.

We sincerely thank the authors and contributors of these projects for their work and contributions to the open-source community.
